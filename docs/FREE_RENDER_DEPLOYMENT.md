# LandSure AI — ফ্রি রেন্ডার (Render) ডেপ্লয়মেন্ট গাইড

এই ডকুমেন্টে LandSure AI FastAPI ব্যাকএন্ডকে কোনো পেমেন্ট বা ক্রেডিট কার্ড তথ্য ছাড়াই Render.com-এর **১০০% ফ্রি টায়ারে (Free Tier)** ডেপ্লয় করার পূর্ণাঙ্গ নির্দেশিকা দেওয়া হয়েছে।

---

## ১. ফ্রি ডেপ্লয়মেন্ট কি সম্ভব? (Is Free Deployment Feasible?)

**হ্যাঁ, সম্পূর্ণ সম্ভব।**
- Render-এর **Free Web Service** প্ল্যানটিতে কোনো ক্রেডিট কার্ড বা পেমেন্ট মেথড ছাড়াই ডেপ্লয় করা যায়।
- পূর্বের `render.yaml`-এ `plan: starter` এবং `disk:` (Persistent Disk) কনফিগার করা ছিল, যার কারণে রেন্ডার পেমেন্ট মেথড যোগ করতে বলছিল (কারণ রেন্ডারে ডিস্ক শুধুমাত্র পেইড স্টার্টার প্ল্যানে অনুমোদিত)।
- এখন `render.yaml` ফাইলটিকে **১০০% ফ্রি প্ল্যান (`plan: free`)** এবং কোনো ডিস্ক ছাড়া আপডেট করা হয়েছে, ফলে রেন্ডার আর কোনো পেমেন্ট ইনফরমেশন চাইবে না।

---

## ২. ফ্রি মোডে কী কী কাজ করবে এবং কী কী বন্ধ থাকবে?

### যা যা সম্পূর্ণ সক্রিয় থাকবে (Working Features):
1. **ডেমো লগইন (`POST /api/v1/auth/demo`)**: ভিজিটররা কোনো ইউজারনেম/পাসওয়ার্ড ছাড়াই ৩০ মিনিটের জন্য রেস্ট্রিক্টেড লাইভ সেশন পাবেন।
2. **৭০০ সিন্থেটিক পার্সেল তথ্য**: জমি খোঁজা, দাগ নম্বর, খতিয়ান, মৌজা, নামজারি ও জরিপ ইতিহাস।
3. **এমএল ইনফারেন্স (ML Review)**: ১৭টি ফিচার ডায়নামিকালি এক্সট্রাক্ট করে লজিস্টিক রিগ্রেশন মডেলের মাধ্যমে জমির ঝুঁকি মূল্যায়ন।
4. **এআই কুয়েরি ও সেফটি গেট**: বাংলা/ইংরেজি প্রশ্নের রাউটিং (Router V4) এবং নিরাপত্তা যাচাই (Safety Gate V2)।
5. **ট্রাস্ট পাসপোর্ট (Trust Passport)**: রিয়েল-টাইম সিন্থেটিক জমি ভেরিফিকেশন রিপোর্ট ও পিডিএফ ডাউনলোড।
6. **CORS ও ক্লাউডফ্লেয়ার ইন্টিগ্রেশন**: `https://landsure-ai.pages.dev` থেকে নিরবচ্ছিন্ন এপিআই এক্সেস।

### যা যা বন্ধ/অনুপলব্ধ থাকবে (Disabled/Unavailable Features):
1. **স্থায়ী অ্যাকাউন্ট তৈরি (Permanent User Registration)**: ফ্রি টায়ারে কন্টেইনার সাময়িক স্লিপ বা রিস্টার্ট হলে লোকাল ডিস্কের ডাটা মুছে যায়। তাই ব্যবহারকারীর তৈরি করা স্থায়ী অ্যাকাউন্ট যেন মুছে গিয়ে বিভ্রান্তি তৈরি না করে, সেজন্য ফ্রি ডেমো মোডে নতুন ইউজার রেজিস্ট্রেশন সার্ভার-সাইড থেকে `403 Forbidden` রিটার্ন করবে।
2. **স্থায়ী বুকিং ও কনসালটেশন সংরক্ষণ**: স্থায়ী ডাটাবেস ছাড়া বুকিং রেকর্ড সাময়িক মেমোরিতে রাখা নিষিদ্ধ করা হয়েছে।

## ৩. ম্যানুয়াল ডেপ্লয়মেন্ট নির্দেশিকা (Manual Render Dashboard Setup)

আপনি যদি ব্লুপ্রিন্ট ব্যবহার না করে রেন্ডার ড্যাশবোর্ড থেকে সরাসরি মাউস ক্লিকে তৈরি করতে চান, তবে নিচের ধাপগুলো অনুসরণ করুন:

### ধাপ ১: রেন্ডার ড্যাশবোর্ডে যান
1. [https://dashboard.render.com](https://dashboard.render.com) এ লগইন করুন।
2. উপরের ডানদিকের **"New +"** বাটনে ক্লিক করে **"Web Service"** বেছে নিন।
3. আপনার গিটহাব একাউন্ট থেকে **`Shihab-10/LandSure-AI`** রিপোজিটরিটি সিলেক্ট করুন।

### ধাপ ২: মূল সেটিংস পূরণ করুন
| ফিল্ডের নাম | কী লিখবেন |
| :--- | :--- |
| **Name** | `landsure-ai-backend` |
| **Language / Runtime** | `Python 3` |
| **Branch** | `main` |
| **Region** | `Singapore` (বাংলাদেশের জন্য দ্রুততম) |
| **Root Directory** | *(ফাঁকা রাখুন)* |
| **Build Command** | `pip install -r backend/requirements.txt` |
| **Start Command** | `python -m uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port $PORT` |
| **Instance Type** | **`Free`** ($0 / month) |

### ধাপ ৩: Environment Variables যোগ করুন
নিচের ভেরিয়েবলগুলো হুবহু যোগ করুন:

| Key | Value |
| :--- | :--- |
| `PYTHON_VERSION` | `3.11.9` |
| `LANDSURE_CORS_ORIGINS` | `https://landsure-ai.pages.dev,http://localhost:5173,http://localhost:3000` |
| `LANDSURE_JWT_SECRET` | *(আপনার নিজস্ব ৩২+ অক্ষরের ক্রিপ্টোগ্রাফিক র‍্যান্ডম স্ট্রিং, যেমন `openssl rand -hex 32` দিয়ে তৈরি)* |
| `LANDSURE_DEMO_ONLY_MODE` | `true` |

### ধাপ ৪: Health Check পাথ সেট করুন
- নিচে **"Advanced"** অপশনটিতে ক্লিক করুন।
- **Health Check Path**-এ লিখুন: `/health`
- **"Deploy Web Service"** বাটনে ক্লিক করুন!

## ৪. লাইভ হওয়ার পর Cloudflare Pages সংযোগ

রেন্ডারে ডেপ্লয় সম্পন্ন হলে একটি ফ্রি পাবলিক ইউআরএল পাওয়া যাবে (যেমন: `https://landsure-ai-backend.onrender.com`)।

Cloudflare Pages-এ গিয়ে:
1. `landsure-ai` প্রজেক্ট ওপেন করুন।
2. **Settings** $\rightarrow$ **Environment variables** এ যান।
3. `VITE_API_URL` ভেরিয়েবলের মান হিসেবে আপনার রেন্ডার ইউআরএল দিন:
   ```text
   VITE_API_URL = https://landsure-ai-backend.onrender.com
   ```
4. সাইটটি একবার **Retry deployment** দিন। এখন লাইভ ক্লাউডফ্লেয়ার ফ্রন্টএন্ড রেন্ডারের ব্যাকএন্ডের সাথে যুক্ত হয়ে সম্পূর্ণ কার্যকর হবে!
